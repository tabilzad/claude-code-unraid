# Security policy

This plugin installs an AI coding agent that runs **as root** on an Unraid server.
Please read `docs/SECURITY.md` for the threat model, what the plugin protects
against, and what it deliberately does not.

## Reporting a vulnerability

Report security issues privately through GitHub security advisories:
<https://github.com/tabilzad/claude-code-unraid/security/advisories/new>.

Do not open a public issue for anything that could let a third party gain
access to a server, bypass the policy baseline, or tamper with the installed
Claude Code binary. You will get an acknowledgement within a few days.

Issues in Claude Code itself belong to Anthropic:
<https://www.anthropic.com/responsible-disclosure-policy>.
